# R1-REG-001 evidence: Entry submission walking skeleton

> Historical report only. The referenced implementation has been deleted; these results do not prove current completion. See [archive context](../README.md).

Status: superseded after implementation removal on September 9, 2026. Previous status: verification in progress

## Delivered slice

- `@docket/registration` owns a minimal Lincoln-Douglas Entry aggregate with `CreateDraftEntry`, `SubmitEntry`, and audience-filtered `GetEntry` operations.
- Registration consumes a narrow Schools-owned eligibility projection for the verified School, active Entry Manager, Competitor affiliation, and Responsible Coach; neither Registration nor application composition reads foreign tables directly.
- Migration 000012 adds source-owned Entry, eligibility-attestation, immutable version, domain-event, command-receipt, and transactional-outbox storage. A partial unique index enforces one active Entry per Competitor and Tournament.
- Fastify exposes the generated Entry operations, the worker claims Registration notice requests, and the accessible React manager surfaces validation, denied, stale, duplicate, recovery, Draft review, submitted, and pending-delivery states.

## Acceptance evidence

- `packages/registration/src/registration-service.test.ts` covers the seeded Draft-to-Submitted path, idempotent replay, duplicate and stale guards, eligibility revalidation, limited Competitor projection, foreign-context denial, and transaction rollback when outbox append fails.
- `packages/registration/src/registration-postgres.integration.test.ts` exercises migration 000012 through the production PostgreSQL stores and proves the submitted Entry confirmation reaches the communications worker, email provider, and Responsible Coach inbox.
- `apps/api/src/registration.test.ts` verifies server-derived session, tab, and idempotency evidence plus the stable stale-version HTTP envelope.
- `apps/web/e2e/entry-submission.spec.ts` is the seeded Playwright keyboard path from Entry form through Draft review to submission and pending confirmation delivery.
- `apps/web/app/components/registration/entry-submission-accessibility.test.tsx` checks the form, validation, review, stale-recovery, and pending-delivery surfaces under WCAG 2 A/AA tags.
