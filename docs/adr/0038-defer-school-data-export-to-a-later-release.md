# Defer School Data Export to a later release

School Data Export is not part of Release 1. The detailed export decisions already developed in ADR 0009 and formerly carried in ADR 0030 are preserved below as design inputs for a future Project Resource Document, but they do not authorize implementation under the current Release 1 work graph.

Release 1 retains represented-School history and its privacy, retention, and access boundaries without building export generation, delivery, sharing, or public verification products. A future release must explicitly define School Data Export scope, work items, executable contracts, capability targets, and acceptance evidence before implementation begins.

## Preserved later-release design inputs

Represented-School export uses a native, permission-aware Docket checklist rather than a packet request. Its fixed School record categories and tournament, season, event, Competitor, record-type, date-range, and format filters cannot expose arbitrary fields or private evidence. CSV is structured and PDF human-readable. One file at or below two gigabytes downloads directly; multiple or oversized output uses ZIP. A single PDF appends its signed integrity page, while CSV is accompanied by a signed PDF manifest inside ZIP. A Docket-signed manifest records the selection, formats, file checksums, counts, and any ZIP sequence; verification keys remain available indefinitely. Exact already-drafted-and-downloaded status includes source versions, filenames follow the fixed convention, CSV schemas are versioned, and formula-triggering user content is neutralized. Fresh Clerk Reverification is required for generation and every new or resumed download without ending the ordinary Docket session; failure denies only that attempt. One active job runs per School and later jobs queue without a daily completion cap. Five user-cancelled or non-system failed jobs in sixty minutes create a one-hour generation-only throttle, while system failures do not count and completed downloads remain available. Cancellation preserves payload-free history and warns that downloaded copies cannot be recalled. School Data Export Permission alone does not expose the Manager's all-School Export History.

School Data Export Permission is indivisible and non-redelegable. A grant requires fresh Manager Clerk Reverification, consequences review, attribution, recipient notice, and recipient acceptance under a current Clerk-authenticated Docket Session within seven days. It ends on revocation or loss of Coaching Staff role or School Membership. Accepted grants survive Manager succession under a persistent seven-day review. Revocation cancels the actor's pending jobs and live or shared downloads without recalling external copies. A permissioned Coach sees only their own two-year activity; the Manager sees all School history. The creator or Manager may share a generated export only with another current permission holder. Private presets disable without transfer on role loss, while Manager-published configuration-only presets survive transitions until retired. Generated files are immutable and source corrections mark them outdated and notify still-authorized downloaders during the delivery-record window. Stable Docket IDs, minimized personal identifiers, ISO timestamps, tournament-timezone context, visible no-tracking attribution, searchable structured PDFs, and verification without record upload apply throughout.

An unreviewed inherited grant suspends after seven days until a freshly reauthenticated successor decision; declined or expired offers close and must be reissued. Coaching Staff may submit an expiring explanation request without receiving authority. Shares end at the earliest of export expiry, explicit revocation, or recipient permission loss, while the Manager retains remaining-window access to completed School output after creator role loss. Manager-published preset edits create attributed versions retained for two years. Generation pins one source-version snapshot, historical rows preserve the Entry ID and represented School, and the preserved design excludes contact-information exports. A former lawful recipient may validate the file signature with public keys, but current School authority is required for live outdated status.
