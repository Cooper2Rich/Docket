## Acceptance criteria

- **R1-TRN-003-A/AC-01** — Publishing a validated Invitation Page exposes the current human-readable accepted information publicly, preserves immutable prior public content, and enters the authenticated active directory; Drafts never appear.
- **R1-TRN-003-A/AC-02** — Cancellation removes registration/Judge actions and every discovery link and sitemap entry, adds noindex, and leaves the direct page readable with Canceled status, date, explanation and prior publications.
- **R1-TRN-003-A/AC-03** — Published corrections append a human-readable notice with old/new public values and effects; API/SSR output excludes fingerprints, exact internal timestamps, actors and restricted evidence.
- **R1-TRN-003-A/AC-04** — For this slice, prove allowed and denied actors, stale version/authority, equivalent retry, conflicting concurrent action, transaction rollback and delivery failure at the authoritative boundary; persist only permitted data and enforce its existing retention/hold contract. For a user journey, exercise its real rendered route with loading, empty, error, denied, stale, mobile and keyboard states. Mark a category inapplicable only with a source-backed reason reviewed in the PR; an omitted case, fake UI, empty suite or unimplemented persistence is not a pass.
