# Docket

Docket is a private project repository.

## Obsidian

This repository is exposed inside the Obsidian **Coding Vault** at `C:\Coding Vault\Docket`. Start with [`wiki/index.md`](wiki/index.md).

The knowledge base follows [Andrej Karpathy's LLM Wiki pattern](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f): immutable curated sources in [`raw/`](raw/), an interlinked LLM-maintained knowledge layer in [`wiki/`](wiki/), and operating rules in [`AGENTS.md`](AGENTS.md).

## Repository map

- `raw/` — immutable source material and source pointers.
- `wiki/` — current synthesized knowledge, navigated through `wiki/index.md`.
- `docs/adr/` — durable architecture decisions.
- `CONTEXT.md` — canonical tournament-domain language.
- `AGENTS.md` — maintenance schema for agents.
